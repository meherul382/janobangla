SAFETY • PHISHING

Phishing Link চেনার ৮টি সহজ লক্ষণ

ভুয়া login page বা জরুরি message দিয়ে ব্যবহারকারীকে দ্রুত সিদ্ধান্ত নিতে বাধ্য করা phishing-এর সাধারণ কৌশল।

কী কী দেখবেন?

  • অচেনা sender বা অস্বাভাবিক email address
  • অতিরিক্ত জরুরি ভাষা বা ভয় দেখানো
  • অস্বাভাবিক domain বা বানান ভুল
  • অজানা attachment
  • password বা verification code চাওয়া
  • অস্বাভাবিক reward বা prize-এর দাবি
  • URL-এর spelling সন্দেহজনক হওয়া
  • আপনাকে দ্রুত link-এ click করতে চাপ দেওয়া

নিরাপদে যাচাই

Message-এর link ব্যবহার না করে সংশ্লিষ্ট service-এর official website বা app নিজে খুলে তথ্য যাচাই করুন।

Password বা one-time verification code কখনোই সন্দেহজনক page বা message-এ শেয়ার করবেন না।
