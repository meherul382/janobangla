File Download-এর আগে যা যাচাই করবেন

JanoBangla · Security

অচেনা website থেকে file download করার আগে source, file type ও expected behavior যাচাই করুন।

Checklist

  • Source trusted কি না দেখুন।
  • File extension পরীক্ষা করুন।
  • অপ্রত্যাশিত executable file এড়িয়ে চলুন।

English Summary

Before downloading a file, verify the source, file type and expected content. Avoid unexpected executable files and use security software where appropriate.
