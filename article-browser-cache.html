Browser Cache Clear করার নিয়ম

JanoBangla · Web Tips

পুরোনো cached files কখনও website-এর নতুন version দেখতে সমস্যা করতে পারে। তখন cache clear করে আবার page load করা যায়।

কখন করবেন?

একটি site বারবার পুরোনো content দেখালে বা loading সমস্যা হলে browser cache পরীক্ষা করতে পারেন।

English Summary

Browser cache stores temporary website files to improve loading speed. Clearing it can help resolve outdated content and some loading issues.

সতর্কতা

Cache clear করলে কিছু website থেকে sign out হতে পারে, তাই প্রয়োজনীয় login information নিশ্চিত করুন।
