SAFETY • PASSWORDS

একাধিক Account-এর Password নিরাপদে ব্যবস্থাপনা

অনেক account-এর জন্য একই password ব্যবহার করলে একটি account compromise হলে অন্যগুলোও ঝুঁকিতে পড়তে পারে।

প্রতিটি গুরুত্বপূর্ণ account-এ আলাদা password

বিশেষ করে email, banking বা অন্য গুরুত্বপূর্ণ service-এর password আলাদা রাখুন।

দীর্ঘ ও অনুমান করা কঠিন password

সহজ নাম, জন্মতারিখ বা সাধারণ শব্দের বদলে দীর্ঘ এবং unique password ব্যবহার করুন।

Password manager বিবেচনা করুন

বিশ্বস্ত password manager দিয়ে unique password সংরক্ষণ করা অনেক account পরিচালনা সহজ করতে পারে।

2-Step Verification

যেসব service সমর্থন করে সেখানে অতিরিক্ত verification layer চালু করুন।

কাউকে password, recovery code বা one-time verification code দেবেন না।
