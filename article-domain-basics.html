Domain Name কী?

JanoBangla · Web Basics

Domain হলো website-এর সহজে মনে রাখার address। এটি hosting থেকে আলাদা; hosting website-এর files serve করে।

উদাহরণ

একটি domain website-এর পরিচিতি তৈরি করে, আর DNS domain-কে সঠিক server-এর দিকে নির্দেশ করে।

English Summary

A domain name is a human-friendly address for a website. Hosting stores or serves the site, while DNS connects the domain to the appropriate server.
