ভালো AI উত্তর পেতে Prompt লেখার সহজ নিয়ম

AI-কে শুধু “একটা লেখা লিখে দাও” বললে ফল অনেক সময় সাধারণ হয়। কাজটি, প্রয়োজনীয় context এবং কাঙ্ক্ষিত format পরিষ্কার করে দিলে উত্তর অনেক বেশি ব্যবহারযোগ্য হতে পারে।

১. কাজটি স্পষ্ট করুন

আপনি কী চান সেটি প্রথমেই বলুন। যেমন—সংক্ষিপ্ত সারাংশ, তালিকা, পরিকল্পনা বা সহজ ভাষায় ব্যাখ্যা।

২. প্রয়োজনীয় Context দিন

কার জন্য লেখা, কোন বিষয় নিয়ে কাজ এবং কী সীমাবদ্ধতা আছে—এসব তথ্য দিলে AI-এর উত্তর আপনার প্রয়োজনের কাছাকাছি হয়।

৩. Output format ঠিক করুন

টেবিল, bullet points, ধাপভিত্তিক উত্তর বা নির্দিষ্ট শব্দসীমা চাইলে তা prompt-এ লিখে দিন।

সহজ formula: Task + Context + Requirements + Output Format

শেষ কথা

একবারে নিখুঁত prompt না হলেও সমস্যা নেই। প্রথম উত্তরের দুর্বল জায়গা দেখে prompt refine করুন।
