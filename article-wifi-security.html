SAFETY • WI-FI

Wi-Fi নিরাপদ রাখার ৮টি সহজ নিয়ম

JanoBangla · Digital Security

বাড়ির Wi-Fi শুধু internet connection নয়; এর সঙ্গে ফোন, কম্পিউটার, smart device এবং কখনও ব্যক্তিগত data যুক্ত থাকে। তাই router-এর basic security settings নিয়মিত দেখা ভালো।

১. Default password বদলান

Router-এর admin account এবং Wi-Fi network-এর জন্য অনুমান করা কঠিন আলাদা password ব্যবহার করুন।

২. Firmware update দেখুন

Router manufacturer-এর official update available থাকলে নির্দেশনা ও compatibility দেখে update করুন।

৩. Encryption ব্যবহার করুন

Router-এ আধুনিক supported wireless security option নির্বাচন করুন। পুরোনো বা দুর্বল security mode এড়িয়ে চলুন।

৪. Connected devices যাচাই করুন

Router-এর device list মাঝে মাঝে দেখে অচেনা device আছে কি না পরীক্ষা করুন।

৫. Guest network ব্যবহার করুন

সমর্থন করলে অতিথিদের জন্য আলাদা guest network ব্যবহার করতে পারেন, যাতে primary network আলাদা থাকে।

৬. Router management দূর থেকে খোলা রাখবেন না

Remote administration প্রয়োজন না হলে বন্ধ রাখা নিরাপদ হতে পারে।

৭. Wi-Fi নাম থেকে ব্যক্তিগত তথ্য বাদ দিন

SSID-তে নিজের নাম, phone number বা ঠিকানার মতো ব্যক্তিগত তথ্য না দেওয়াই ভালো।

৮. অস্বাভাবিক activity হলে settings review করুন

বারবার অচেনা device বা অস্বাভাবিক network behavior দেখলে router settings এবং connected devices পরীক্ষা করুন।

English Summary

Keep home Wi-Fi safer by using strong unique passwords, supported encryption, router updates and regular device reviews. Disable unnecessary remote administration and consider a guest network.
